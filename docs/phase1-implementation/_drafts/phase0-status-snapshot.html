Still needed before Phase 0 launch

  1. Browser extension: not started.
  2. UTM reporting and the click event list endpoint.
  3. Frontend gaps: CSV import screen, folder/tag filters, Arabic/English, and moving the session token out of localStorage into a server-side session cookie.
  4. Configure and test real services: Stripe, Google Web Risk, Google/GitHub sign-in, GeoIP.
  5. Infrastructure: Nginx, production Docker Compose (secrets, networks, limits), CI pipeline, backups.
  6. Hardening required by the build spec v9.4: separate database roles per service, off-host allocator storage (S3), operator CLI for init and recovery, and the chaos, architecture and mutation test suites. These are not PRD features but the spec requires them for production.

Decisions needed

  • Scope conflict. The build spec v9.4 says "short links only" and puts billing out of scope. The PRD and the current code include password gates, routing rules, Stripe and Free/Starter plans. Which document governs Phase 0?
  • Code length. The PRD asks for 6-character random codes; the spec starts at 5 characters and grows. The code follows the spec.
